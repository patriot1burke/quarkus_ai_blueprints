# Leverage Enterprise Java

AI Applications don't exist in a vacuum.  Your AI Chat App will need to pull information and data from existing systems and microservices.
Your Agentic Workflows will need to publish and subscribe to event-driven systems that already exist in your organization.
The Quarkus platform as a whole integrates with all the popular Enterprise Java frameworks you love and have been using
for years:  Hibernate, Camel, REST (JAX-RS), Kafka, etc.).

Quarkus also has a rich ecosystem of hundreds of extensions written by the Quarkus community.  
Browse the extensions catalog on [code.quarkus.io](https://code.quarkus.io) and [extensions.quarkus.io](https://extensions.quarkus.io) 
to see what's available.
