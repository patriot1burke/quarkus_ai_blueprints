# Deploy

## Quarkus already runs everywhere!

One of the key benefits of writing AI-Applications with Quarkus is that you inherit all the benefits of a mature
Enterprise Java stack.  When deploying your AI Application you'll find that because you used Quarkus, you can deploy it
anywhere.  Quarkus has integration and support to run on OpenShift, Kubernetes, AWS, AWS Lambda, Azure, and Azure Functions
and many other platforms.

* [Build a Container Images](https://quarkus.io/guides/container-image)
* [Deploy to OpenShift](https://quarkus.io/guides/deploying-to-openshift) 
* [Deploy to Kubernetes](https://quarkus.io/guides/deploying-to-kubernetes)
* [Deploy to AWS](https://aws.amazon.com/blogs/containers/how-to-deploy-your-quarkus-application-to-amazon-eks/)
* [Deploy to AWS Lambda](https://quarkus.io/guides/aws-lambda)
* [Deploy to Azure](https://quarkus.io/guides/deploying-to-azure-cloud)
* [Deploy to Azure Functions](https://quarkus.io/guides/azure-functions)
* [Deploy to Google Cloud](https://quarkus.io/guides/deploying-to-google-cloud)
