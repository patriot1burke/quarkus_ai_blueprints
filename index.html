Write AI-Infused Applications

Write AI-infused applications

Quarkus AI gives your application the vocabulary to talk to models, call tools, retrieve knowledge, and act — all as ordinary CDI beans.

AI Services

LLM interactions, declared not wired.

LangChain4j gives Quarkus AI an abstraction layer over whichever model you choose — OpenAI, Ollama, and the rest of the LangChain4j catalogue — so switching providers is a config change, not a rewrite. Annotate a plain Java interface and Quarkus generates the AI Service that talks to the model for you.

Weatherman.java
@RegisterAiService
public interface Weatherman {

    @SystemMessage("You are a weatherman.  Answer questions about the weather.")
    String ask(@UserMessage String query);
}

Architecture at a glance: your code calls the interface, Quarkus AI routes the call through LangChain4j to the configured model, and hands back a typed response.

Tools

Give the model hands.

Annotate any CDI bean method with @Tool and describe what it does in plain language. Quarkus AI exposes it to the model through LangChain4j and handles the call-and-return loop, so the LLM can ask for the forecast instead of guessing at it.

WeatherToolbox.java
@ApplicationScoped
public class WeatherToolbox {
    @Inject
    WeatherAPI weather;

    @Tool("Get the current weather for a specific city")
    public String currentWeather(String city) {
        return weather.currentEither(city);
    }

    @Tool("Get the 10 day weather forecast for a specific city")
    public List<String> tenDayForecast(String city) {
        return weather.tenDayForecastEither(city);
    }
}

@RegisterAiService
public interface Weatherman {

    @SystemMessage("You are a weatherman.  Answer questions about the weather.")
    @Toolbox(WeatherToolbox.class)
    String ask(@UserMessage String query);
}

Guardrails

Safety controls between user and model.

Guardrails are the safety layer between a user and the model — real-time checks on what goes in and what comes back out, keeping the system on topic and inside legal and brand lines, without touching the model itself. Quarkus AI ships a library of built-in guardrails and an API for writing your own.

Glued Together with CDI

Every AI component is a CDI bean.

Every AI component — AI Services, Tools, RAG, agents — is a CDI bean, so the rest of Quarkus Core is never more than an @Inject away.
